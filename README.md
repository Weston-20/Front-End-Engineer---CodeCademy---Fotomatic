# Front-End Development Landing Page Example Website - Fotomatic

## Summary
This project gives you the blueprint and resources, and asks you to create a landing page, that uses @media profiles in the CSS to shape the website based upon the specification of your device screen aspect ratio.

## Features
+ Screen Adaption Formatting
+ Flex-bot foundation
+ Asset management and scaling
+ Blueprint specification

## Sources
CodeCademy Front-End Engineer Professiona Certification

### What I learned
The key takeaway challenge from this landing page website was the scaling in CSS, using @media customisation. This makes you more about the bigger picture of the website, and how you want the user to view your design on multiple platforms, and not just the one you are currently working on/ primarily focussed on.
